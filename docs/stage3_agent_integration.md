### 4. 中枢调度智能体工作流

**核心协同工作流**（Graph模式）：

```
用户需求输入 
    ↓
获取用户最新画像
    ↓
拆解任务并分发（并行）
    ↓
    ├─→ 画像任务 → 学生画像智能体
    ├─→ 资源任务 → 6个资源智能体并行
    ├─→ 路径任务 → 学习路径规划智能体
    ├─→ 辅导任务 → 智能辅导智能体
    └─→ 评估任务 → 学习效果评估智能体
    ↓
内容安全与防幻觉智能体统一校验
    ↓
中枢调度智能体整合结果
    ↓
返回前端展示
    ↓
数据同步至画像与评估模块
```

**异常处理机制**：
- 单个智能体失败：自动重试3次
- 仍失败：上报异常，返回友好提示
- 不影响系统整体运行
- 记录完整错误日志
